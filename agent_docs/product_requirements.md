# Product Requirements

Use this as the short build-facing version of the PRD. Do not paste the entire PRD unless the project is complex.

## Users

- Primary user: A mobile user scanning fictional insider-activity signals; ArkLab AI reviewers are the evaluation audience
- Main problem: Make fictional disclosure-style activity easy to scan, filter, and understand on mobile without implying real data or investment advice

## Must-Have Features

- Market Pulse — visible fictional-data treatment, three derived summaries, top signals, four recent cards, and navigation
- Screener — case-insensitive ticker/company search, three independent filter groups, combined filtering, count, empty state, and reset
- Trade Details — matching record fields, mock seven-day chart, educational copy, exact disclaimer, and working back action

## Nice-To-Have Features

- Preserve Screener state when returning from Details
- Focus Screener search when entered through the Home search affordance

## Out Of Scope

- Live financial data, APIs, scraping, or copied StockInsider.io content
- Authentication, backend, portfolios, alerts, settings, and in-product AI

## Success Signals

- Every assignment acceptance item is demonstrable and static checks pass
- The final APK installs, launches, and completes the required three-screen journey
